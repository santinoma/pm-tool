# Capability Map: Next-Elite Design Migration

Ersetzt alle drei bestehenden Oberflächen-Generationen (v1 Apple-HIG in `globals.css`, v2 in `ui/v2/theme.css`, v3-Vorversion in `ui/shadcn/*` für `(platform-admin)/v3`) durch ein einziges, app-weites Design im Next-Elite-Stil (Tailwind CSS 4 + shadcn/ui + Framer Motion), übernommen aus https://github.com/salmanshahriar/Next-Elite. Rollout erfolgt **inkrementell pro Modul** — ein Modul wird komplett auf das neue Design migriert und verifiziert, bevor sein v1/v2/v3-Code gelöscht wird. Die App bleibt während der gesamten Migration durchgehend benutzbar.

Nicht Teil dieser Migration (bleibt unverändert): Subdomain-Routing (`src/proxy.ts`, `tenant/resolveTenant.ts`), Auth-/Session-Mechanik, alle Server-Aktionen/API-Routen, Prisma-Schema. Jedes Modul muss nach seiner Migration verifizieren, dass Subdomain-Routing (`admin.localhost`, `<tenant>.localhost`) weiterhin korrekt funktioniert — das ist eine Regressions-Prüfung, kein Bauteil dieser Migration.

**Build-Reihenfolge:**
`design-foundation` → `platform-admin`, `auth` → `dashboard` → `projects` → `my-tasks`, `time`, `members`, `portfolios`, `reports`, `resource-planning`, `financials`, `notifications` → `settings` → `portal`

(`settings` bewusst spät: 21 Unterseiten mit vielen Querbezügen zu bereits migrierten Modulen. `portal` zuletzt: eigene, reduzierte Oberfläche für die Kunden-Rolle, hängt von `auth` ab.)
